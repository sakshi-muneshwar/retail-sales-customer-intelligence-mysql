# Retail Sales & Customer Intelligence Analytics Using MySQL

## Project Overview
This project focuses on analyzing retail sales data using MySQL to understand sales performance, customer behavior, product trends, and business insights.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
- Customers
- Products
- Employees
- Orders
- Order_Items

## Project Objectives
- Analyze overall sales performance.
- Identify top-selling products.
- Understand customer purchasing behavior.
- Evaluate employee sales performance.
- Generate meaningful business insights.

## Project Files
All SQL scripts and project files are available in the `sql` folder.
